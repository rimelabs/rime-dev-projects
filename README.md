## What belongs here

Projects should have been built at a developer event, use Rime for a meaningful part of the primary voice experience, and have public source code that others can inspect. Before a project is listed, we also check that its repository does not expose live credentials.

The linked projects remain owned by their builders and use the licenses in their source repositories. Inclusion here is a showcase, not a transfer of ownership or a blanket endorsement of every implementation decision.
